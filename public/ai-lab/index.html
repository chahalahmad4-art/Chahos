Browser replies are source extracts or reviewed Lebanese translations, not generated text. Keyword retrieval does not understand every paraphrase.

Architecture & honest limitations

TXT/Markdown ingestion → overlapping passages → SHA-256 library version → instruction-pattern quarantine → BM25 top-3 retrieval → abstention when no match → evidence display. The backend adds optional grounded LLM generation and records metadata without raw prompts. Lexical matching can retrieve a related passage that does not answer the exact question. The heuristic safety filter can miss adversarial inputs; it is not a security boundary. The generator cannot call tools. PDF parsing and semantic embeddings are not included.

Architecture & integration boundary

Optional LLM selects one allowlisted tool: knowledge search, trial suggestion or human handoff. The server validates tool arguments; the model cannot access the database or send messages. What these metrics do and do not prove

Latency is measured per request; p95 uses the nearest-rank method. The browser trace buffer contains this session only. The server retains its latest 500 traces. The suite checks a small fixed set, not general robustness, live model quality or production reliability. Model token usage is recorded by the backend when the provider supplies it; monetary cost is not guessed. No fabricated customers, revenue gains or accuracy claims.
